# Kanta Fujiwara - Personal Website

A simple static academic website designed for GitHub Pages.

## Files

- `index.html` — Home
- `research.html` — Research
- `publications.html` — Publications
- `cv.html` — CV
- `contact.html` — Contact
- `style.css` — Site design

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `kanta-fujiwara.github.io`.
2. Upload all files in this folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select the branch containing these files (normally `main`) and the root folder.
5. GitHub Pages will publish the site.

If the repository name is exactly `<username>.github.io`, the main site URL will usually be:
`https://<username>.github.io/`

## Things to customize before publishing

- Replace the email placeholder in `contact.html`.
- Add ADS / ORCID / Google Scholar / GitHub links.
- Add a profile photo if desired.
- Update CV dates and publication entries.
- Add `cv.pdf` and link it from `cv.html` if desired.
